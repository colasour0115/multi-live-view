# Multi Live View

YouTube・Twitch・Kick の配信や動画を、Google Chrome 上の自由なホワイトボード空間に複数並べて同時視聴できるローカルマルチビューアプリです。

普段お使いの Chrome 上で動作するため、**YouTube / Twitch のログイン状態や拡張機能などをそのまま活かしつつ**、快適な複窓環境を構築できます。

---

## 主な機能

- **自由なボード配置＆スナップ整列**: ドラッグ移動・8方向リサイズ・スナップ吸着・隣接ウィンドウ連動リサイズ（スプリッター）
- **ワンクリック整列＆配置プレビュー**: 「オート（並び順から最適配置）」「2〜4分割」「メイン＋チャット」に加え、プレビュー画面で枠ごとの配置を自由に入れ替え可能
- **フォーカス連動モード**: 選択中のウィンドウの音声だけを自動再生し、右固定（またはウィンドウ化可能）の連動チャット欄を選択中の配信へ瞬時に切り替え
- **プロ仕様オーディオミキサー**: マスター音量・縦横フェーダー切替・ソロ（S）／ミュート（M）・ポップアップ／ウィンドウ両対応
- **Chrome 拡張機能連携**: 見ている配信ページからワンクリックでボードへ送信。拡張機能クリックでローカルサーバーを自動起動し、ボードを閉じると自動で終了
- **ライブ配信中まとめ＆お気に入り**: 登録した YouTube / Twitch チャンネルの配信状況をリアルタイム監視し、配信中の枠をまとめて表示・一括起動
- **仮想ボード＆レイアウトプリセット**: 用途別にレイアウトを保存・復元可能
- **YouTube VOD 対応**: 非ライブ動画のリロード時再生位置復元、再生終了時のおすすめ動画表示
- **ダーク / ライトテーマ・設定カスタマイズ**: サイト別初期音量、ウィンドウボタンの表示／非表示、左メニュー自動折りたたみ

## 無料版と PRO 版の違い

| 機能 | 無料版（Free） | PRO 版（制限なし） |
| :--- | :---: | :---: |
| 整列・連動チャット・ミキサー・拡張連携 | 利用可能 | 利用可能 |
| 動画ウィンドウ同時表示数 | **6 画面まで** | **無制限** |
| お気に入りチャンネル登録数 | **5 件まで** | **無制限** |
| レイアウトプリセット保存数 | **2 件まで** | **無制限** |
| ボードの別ウィンドウ化 | — | **利用可能** |

※ 無料版から PRO 版へ移行する際は、フォルダ内の `multiview-data.json` を引き継ぐだけでお気に入りや設定をそのまま使えます。

## 導入手順（Windows）

### 1. ZIP を展開してセットアップ
1. 配布 ZIP をお好みのフォルダ（例: `C:\Apps\MultiLiveView`）にすべて展開します。
2. フォルダ内の **`install.bat`** をダブルクリックして実行します（Chrome 拡張機能から自動起動するための設定が登録されます。管理者権限は不要です）。

### 2. Chrome 拡張機能を読み込む
*(Chrome ウェブストア公開版をお使いの場合はストアから「Chrome に追加」するだけで完了です)*

1. Google Chrome で `chrome://extensions/` を開きます。
2. 右上の **「デベロッパー モード」** を ON にします。
3. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、展開したフォルダ内の **`chrome-extension`** フォルダを選択します。

### 3. 起動方法
- ツールバーの **Multi Live View 拡張機能アイコン** をクリック → **「開いているボードへ切替 / 開く」**（または配信ページを開いた状態で **「▶ ボードに表示」**）を押すと自動でボードが開きます。
- 拡張機能を使わずに起動したい場合は、フォルダ内の **`start.bat`** をダブルクリックしても開けます。

## よくある質問（FAQ）

### Q. 別タブに移動すると Twitch の音が止まります
Twitch 公式埋め込みプレイヤーの仕様により、同じ Chrome ウィンドウ内の裏タブに移動すると再生が停止します。  
ボードのタブをドラッグして別の Chrome ウィンドウに切り離す（PRO 版では「別ウィンドウでボードを開く」ボタンも利用可能）と、他ウィンドウで作業中も音が止まらず視聴できます。

### Q. F5 更新時に自動で音が出ません
Chrome のアドレスバー左側のアイコン → **「サイトの設定」** → **「音声」を「許可」** に変更すると、リロード直後から音声付きで自動再生されます。

### Q. アンインストールしたいときは？
フォルダ内の **`uninstall.bat`** を実行してから、フォルダと Chrome 拡張機能を削除してください。
