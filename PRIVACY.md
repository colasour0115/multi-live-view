# Privacy Policy / プライバシーポリシー

**Multi Live View Sender** (Chrome Extension) & **Multi Live View** (Local Web App)

Last updated: 2026-11-26

---

## 日本語

### 1. 収集する情報について
Multi Live View および Chrome 拡張機能「Multi Live View Sender」は、ユーザーの個人情報、閲覧履歴、アカウント情報、Cookie などを **外部サーバーへ送信・収集・販売することは一切ありません**。

### 2. データの保存先と通信範囲
- 拡張機能が取得する「現在開いているタブの URL およびタイトル」は、ユーザーが拡張機能内のボタンをクリックしたタイミングでのみ、ユーザー自身の PC 上で動作するローカルサーバー（`http://localhost:3456`）へ送信されます。
- お気に入りチャンネル・設定・レイアウトプリセット等のデータは、すべてユーザー自身の PC 内（ブラウザの `localStorage` およびアプリフォルダ内の `multiview-data.json`）のみに保存されます。
- ライブ配信状況の確認のため、ローカルサーバーから YouTube および Twitch の公開ページ／公開エンドポイントへ直接アクセスを行いますが、ユーザーを特定する個人情報は含まれません。

### 3. 第三者提供について
本ソフトウェアは、いかなるユーザーデータも第三者に提供・共有しません。

### 4. お問い合わせ
プライバシーポリシーに関するご質問は、配布ページ（GitHub / BOOTH）の連絡窓口よりお問い合わせください。

## English

### 1. Data Collection
**Multi Live View** and the **Multi Live View Sender** Chrome extension do **not** collect, transmit, store, or sell any personal data, browsing history, credentials, or cookies to any external or third-party servers.

### 2. Local Processing Only
- The active tab's URL and title are read **only** when the user explicitly clicks a button in the extension popup, and are sent exclusively to the user's own local server running on `http://localhost:3456`.
- All user preferences, favorite channels, and board layouts are stored strictly on the user's local device (`localStorage` and local `multiview-data.json`).
- Native Messaging (`com.multiviewpro.launcher`) is used solely to launch the local server on the user's own computer when requested by the user.

### 3. Third-Party Sharing
No user data is shared with or transferred to any third parties.

### 4. Contact
If you have questions regarding this privacy policy, please contact the developer via the official distribution page (GitHub / BOOTH).
